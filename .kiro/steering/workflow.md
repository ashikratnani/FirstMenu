# Workflow

- Work on a branch and open a pull request into `main` for every change.
- The maintainer has approved Kiro merging its own pull requests into `main` without waiting for review, once checks pass.
- Changes to CI/CD files (`.github/workflows/*`) still go through a pull request, never a direct push to `main`.
- Never force-push to `main` or rewrite its history.
